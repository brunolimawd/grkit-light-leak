安装 Light Leak（漏光）

如何安装

将 LITLEAK.GRM 复制到 SD 卡

漏光是独立的非官方 GRKit 模块，从 SD 卡加载，不修改相机固件。

下载 LITLEAK.GRM

测试版 v0.1.0-beta.1 · GRM 修订号 16

兼容性

漏光模块已在理光 GR III（固件 2.10）上通过真机测试。GR IIIx、GR IV 和其他机型或固件组合尚未用此模块进行真机验证。

机型固件状态
理光 GR III2.10已通过真机测试

需要支持模块 ABI 2.7 的 GRKit 运行环境，且至少还有一个外部模块空位。参考构建使用 GRKit 1.6.6。请参阅兼容性记录（英文）和 GRKit 官方安装指南。

复制文件

  1. 下载 LITLEAK.GRM。取出 SD 卡前，先关闭相机。
  2. 从 SD 卡根目录起，将文件复制到 GRKIT/MODULES/LITLEAK.GRM。更新时直接替换旧文件。不要复制到 SCRIPT/GRKIT/MODULES。
  3. 插回 SD 卡并开机，等 ADJ 菜单中出现 GRK 后，打开 ADJ → GRK → 漏光。

如果没有显示「漏光」，请检查 GRKIT/REPORT.TXT，并确认 GRKit 还有外部模块空位。

卸载或恢复

关闭相机，再从 SD 卡删除 GRKIT/MODULES/LITLEAK.GRM，即可卸载。如果相机在菜单打开前停止响应，请按 GRKit 模块恢复说明（英文）操作，或参阅简体中文恢复指南。
