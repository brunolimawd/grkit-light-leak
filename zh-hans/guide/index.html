Light Leak（漏光）使用指南

选择漏光样式，决定光线从画面的哪一侧进入，再设置每张照片的效果如何变化。

拍摄第一张照片

  1. 打开 ADJ → GRK → 漏光，选择六种样式之一。默认设为「关闭」。
  2. 按 Fn 调整强度、漏光位置和变化。要重现网站的示例，请选择「中」、「原始位置」和变化 1。
  3. 拍摄后回放 JPEG 查看结果。取景图标只提示当前样式，不显示实际漏光效果。

六种漏光样式

以下描述以变化 1 为例。每种样式都可调节强度、入光侧和变化。

缝隙光束
白色光束、红色光幕和青色反光。默认从右侧进入。
烧灼边缘
不规则的明亮细缝，带红橙色溢光。默认从右侧进入。
胶片光带
金色光带，带红色边缘和冷色晕边。默认从底部进入。
琥珀光幕
一片琥珀色光斑，带斜向的红色尾迹。默认从顶部进入。
棱镜光弧
由红、金、蓝绿和蓝色组成的光弧。默认从右侧进入。
彩色光雾
由金色、蓝绿、蓝色和玫红交织而成的斜向光雾。默认从顶部进入。

各项设置的作用

强度
弱、中、强三档，默认为「中」。
漏光位置
右侧、左侧、顶部、底部、随机或原始位置。「原始位置」使用当前样式的默认入光侧。方向以传感器为准，竖拍时会随画面旋转。
变化
1 保留原始形状和配色，2 和 3 会改变两者。默认的「自动」会为每张照片选择一种变化，不改变所选的样式、强度或位置。
随机样式
为每张照片随机选择样式、强度和位置，不改动已保存的设置。选择固定变化时就使用该变化；设为「自动」时才随机选择变化。连续拍摄可能得到相同结果。

主 JPEG 和它的预览使用同一次随机选择。拍摄单色照片时，漏光只增加亮度，不添加色彩。

取景图标

「图标显示」开启时，在静态照片取景的 DISP 完整信息模式下，屏幕左侧会显示漏光图标。一格、两格或三格白色标记分别表示弱、中、强。「随机」样式显示没有强度标记的骰子图标。图标不会写入照片。

显示图标时，相机的原生网格线可能会被隐藏。可以通过 Fn → 图标显示 → 关闭 恢复原来的网格线显示方式，或改用 GRKit 的辅助线模块。

常见问题

漏光会改动 RAW 文件吗？ #

不会。效果应用于 JPEG 及其预览，不修改传感器的原始数据。

拍摄前能预览效果吗？ #

不能。漏光没有实时预览。取景图标只提示当前样式，以及能在拍摄前确定的强度。

支持 GR IIIx 或 GR IV 吗？ #

这些机型还没有用此模块进行真机验证。目前已测试的是理光 GR III（固件 2.10）。参阅兼容性说明。

漏光效果会保存到配方吗？ #

不会。GRKit 的配方不会保存漏光模块的设置。

漏光与其他效果的应用顺序是什么？ #

漏光在胶片风格和光晕之后应用，早于胶片颗粒和加印日期。它不会给额外添加的边框染色。

LITLEAK.GRM 放在哪里？ #

从 SD 卡根目录起复制到 GRKIT/MODULES/LITLEAK.GRM。参阅安装步骤。
