# Changelog

## v16 — first standalone release

- Six film light leaks with four entry sides, three strengths and three
  variations. Auto and Random use one draw for the JPEG and its previews.
- A distinct viewfinder symbol for each style and strength. Show Icon
  defaults to On; a previously saved preference is kept.
- The standalone module keeps the `LITLEAK` ID, version 16 and existing
  saved settings from the v16 integration build.
- Hardware tested on a RICOH GR III with firmware 2.10.
