SD card setup

Install Light Leak

Light Leak is a separate, unofficial GRKit module. It runs from your SD card and does not modify the camera firmware.

Which cameras are tested?

Light Leak has been tested on a RICOH GR III with firmware 2.10. The GR IIIx, GR IV and other model or firmware combinations have not been verified on hardware for this module.

CameraFirmwareStatus
RICOH GR III2.10Tested on hardware

You also need a GRKit runtime compatible with module ABI 2.7 and a free external module slot. The reference build uses GRKit 1.6.6; see the compatibility record and the official GRKit installation guide.

Install or update

  1. Get LITLEAK.GRM from a module release and turn your camera off before removing the SD card.
  2. Copy the file to GRKIT/MODULES/LITLEAK.GRM from the root of the card. If updating, replace the old file. Do not put it in SCRIPT/GRKIT/MODULES.
  3. Reinsert the card, turn on the camera and wait for GRK to appear in ADJ. Open ADJ → GRK → Light Leak.

If Light Leak does not appear, check GRKIT/REPORT.TXT and confirm that GRKit has a free external module slot.

Remove or recover

Turn the camera off, then delete GRKIT/MODULES/LITLEAK.GRM from the SD card to uninstall the module. If the camera stops before the menu opens, follow the GRKit module recovery instructions.
